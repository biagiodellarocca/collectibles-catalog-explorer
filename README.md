# Collectibles Catalog Explorer

React + TypeScript catalog app (search, filters, wishlist, virtualized lists)
built as a portfolio project over a 16-day sprint (Aug 28 - Sep 12, 2026).

Stack: Vite, React, TypeScript, react-router-dom, react-window, Bootstrap,
json-server, Vitest + React Testing Library, Docker, GitHub Actions.

A full architecture write-up (mapping features to the job requirements they
demonstrate) lands here on the last day of the sprint. For now: work in progress.

## Dev

```
npm install
npm run dev
```
